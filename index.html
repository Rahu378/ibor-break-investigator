      Benchmark

      200 breaks. Six root causes. Scored against the seeded labels.

      The breaks come out of an actual recon run over two synthetic books, so the labels are known. The agent never sees them: the answer key isn't on its SQL allow-list and isn't granted to its database role.

      How it works

      Read-only by construction. Human by default.

      Recon warehouse

      PostgreSQL. Positions, trades, settlements, corporate actions, prices, FX, cash.

      role: breakbot_agent · SELECT only · read-only txn · 5s timeout

      SQL guard

      sqlglot parses every statement. One SELECT, allow-listed tables, banned functions, LIMIT added.

      Tools

      positions · recent_trades · corporate_actions · prices · fx · unmatched_cash · run_sql. Each call gets a query id.

      Investigator

      Claude with tool use, or the deterministic playbook. Quantifies each hypothesis against the break amount.

      LangGraph

      check_citations rejects dangling [Qn:rm] references. human_review is an interrupt: the run parks until someone decides.

      Analyst

      Streamlit queue. Approve, edit the cause / fix / owner team, or reject back to manual.

      Audit

      Every node, query and decision appended to a separate audit store the agent can't write to.

      What the agent can see

      Tables in the warehouse. The answer key is in the same database and still out of reach.
